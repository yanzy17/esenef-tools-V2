# Esenef Tools — Digital Seller Assistant

Esenef Tools adalah web app static ringan untuk membantu pemula jualan produk digital, affiliate Shopee/TikTok, reseller digital, dan kreator konten yang sering blank saat promosi.

Tools ini fokus ke satu fitur utama: **Buat Paket Promosi Lengkap**. User cukup masukin nama produk, lalu tools bantu menyusun strategi promosi siap pakai.

## Fungsi Utama

Digital Seller Assistant membantu membuat paket promosi yang berisi:

- Analisis produk singkat
- Target audiens otomatis
- Angle konten
- Hook siap pakai
- Caption siap posting
- CTA halus
- Script video pendek
- Template balasan DM
- Rencana posting 5 hari

## Target Pengguna

Tools ini cocok untuk:

- Pemula jualan dari HP
- Affiliate Shopee
- Seller TikTok Shop
- Reseller produk digital
- Kreator konten yang butuh ide promosi
- Pemilik produk yang bingung menentukan angle jualan

## Cara Pakai

1. Buka `index.html` langsung di browser.
2. Isi **Nama produk**.
3. Kalau mau, pilih jenis produk, platform promosi, gaya konten, dan level kebutuhan.
4. Klik **Generate Paket Promosi**.
5. Copy bagian yang dibutuhkan atau klik **Copy Semua**.
6. Gunakan tombol regenerate style untuk bikin hasil lebih santai, soft selling, relate, atau singkat.

## Fitur Utama

- Generator promosi berbasis template pintar tanpa backend.
- Output tetap lengkap meski user cuma isi nama produk.
- Template kategori untuk Produk Digital, Affiliate Shopee, TikTok Shop, Skincare, Fashion, Alat Rumah, Makanan, dan Lainnya.
- Tombol copy di setiap card output.
- Tombol **Copy Semua**.
- Regenerate style: lebih santai, soft selling, relate, dan singkat.
- Loading state yang terasa seperti asisten.
- Toast notification saat copy berhasil.
- Riwayat 5 hasil terakhir memakai `localStorage`.
- Desain responsive, mobile-first, dan siap GitHub Pages.

## Teknologi

Project ini dibuat tanpa framework dan tanpa build tool:

- `index.html`
- `style.css`
- `script.js`
- `README.md`

Semua file ringan dan bisa langsung dijalankan sebagai static website.

## Deploy ke GitHub Pages

1. Push repo ini ke GitHub.
2. Buka **Settings** repository.
3. Masuk ke menu **Pages**.
4. Pada bagian **Build and deployment**, pilih source dari branch utama, misalnya `main`.
5. Pilih folder root `/`.
6. Klik **Save**.
7. Tunggu GitHub Pages selesai deploy, lalu buka URL yang diberikan.

Karena project ini static murni, tidak ada konfigurasi tambahan yang dibutuhkan.
